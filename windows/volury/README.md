# Volury

Editor de e-books (EPUB 2 & 3) para a **Quilly Suite**.

Inspirado no [Vellum](https://vellum.pub/) e baseado nas funcionalidades do [Sigil-Ebook](https://github.com/Sigil-Ebook/Sigil).

## Funcionalidades

- Criar, abrir e editar e-books no formato EPUB
- Editor visual (WYSIWYG) e editor de código (HTML/CSS)
- Gerenciamento de capítulos com drag-and-drop
- Inserção de imagens e folhas de estilo CSS
- Geração automática de sumário (Table of Contents)
- Validação de conformidade EPUB
- Importação de arquivos `.hyp` (Noty/Artry)
- Integração com a Quilly Suite

## Build

```powershell
.\build.ps1
```

## Requisitos

- .NET 10 SDK
- Windows 10/11 (x64)
