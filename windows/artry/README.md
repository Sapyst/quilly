# Artry

Editor de texto minimalista, rápido e elegante: uma experiência unificada para escrever, editar documentos ricos e manipular código sem atrito. Disponível para Windows (Desktop e Instalador) e Android (APK nativo).

## Identidade Visual e Design

- **Tema Dark Pro**: Inicialização em tons de cinza escuro profissionais (`#181A1D` desk, `#22252A` folha do documento, `#282C31` barras e superfícies).
- **Acento Amarelo Artry**: Destaque interativo de alto contraste com o amarelo da marca (`#FFDE00` / `#FFF200`) e tipografia em preto carvão profundo (`#121418`) nas sobreposições e seleção, garantindo legibilidade máxima.
- **Ícone Oficial**: Formato squircle com a letra 'a' estilizada e transparência alfa ARGB de 32 bits.

## Formatos Suportados

Abre e salva `.artry`, `.docx`, `.rtf`, `.txt`, `.md`, `.html`, `.json`, `.xml`, `.csv` e extensões de código (`.cs`, `.py`, `.js`, `.ts`, `.sql`, `.ps1`, `.sh`, etc.).

## Atalhos Principais

`Ctrl+O` abrir · `Ctrl+S` salvar · `Ctrl+Shift+S` salvar como · `Ctrl+P` imprimir · `Ctrl+F` localizar · `Ctrl+H` substituir · `Ctrl+B/I/U` formatar · `Ctrl+G` ir para linha · `F11` tela cheia · `Ctrl+W` alternar quebra de linha · `Ctrl+R` régua VxH · `Ctrl+L` números de linha.

## Distribuição e Executáveis

1. **`Artry.exe`**: Executável desktop Windows standalone de arquivo único.
2. **`Artry-Installer.exe`**: Instalador completo com assistente visual, atalhos na Área de Trabalho e Menu Iniciar, e integração de extensões no Windows.
3. **`Artry.apk`**: Aplicativo móvel para Android pronto para instalação via sideload.
